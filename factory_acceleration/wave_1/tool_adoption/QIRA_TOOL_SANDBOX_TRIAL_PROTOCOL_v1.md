# QIRA Tool Sandbox Trial Protocol v1

Zero-trust tool admission requires explicit purpose, read/write set, network policy, install policy, credential policy, telemetry policy, cache/state containment, timeout policy, license/IP review, Windows behavior, active root access limits, rollback/uninstall plan, allowed and forbidden routes, sandbox trial, output evidence, and proof ceiling.

This protocol forbids active repo scanning by default and requires no-install/no-network proof or separate authorization.

Proof ceiling: QIRA_FACTORY_ACCELERATION_SUPERWAVE_1_ARTIFACTS_AND_TOOL_ADMISSION_DEFINED_WITH_LIMITS_NO_INSTALL_NO_NETWORK_NO_RUNTIME_NO_TESTS_NO_VALIDATION_NO_READINESS_PROOF
