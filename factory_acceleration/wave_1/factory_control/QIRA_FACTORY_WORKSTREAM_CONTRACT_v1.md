# QIRA Factory Workstream Contract v1

Default lifecycle: preflight; accepted evidence basis; exact mutable set; forbidden operations; autonomy boundaries; stop rules; partial-state handling; evidence contract; proof ceiling; postflight QG; next route.

Default execution mode is broad bounded superwave. Micro-step mode is reserved only for material blockers: contract ambiguity, old-root risk, secret/data risk, real-data/validation risk, source/runtime mismatch, tool install/network risk, partial creation, unauthorized mutation, or proof-ceiling violation.

Every artifact must support closure evidence, golden behavior, routing, tool admission, deterministic verification, security baseline, authorization boundary, or claim control. Narrative-only artifacts are not admissible.
